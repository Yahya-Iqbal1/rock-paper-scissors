# Rock Paper Scissors Game ✊📄✂️

> *A feature-rich console game built with Python*

---

## 💡 What is this?

A fun and interactive Rock Paper Scissors game built in Python with score tracking, win streaks, stats, and a clean console UI.

---

## ✨ Features

- ✊ **Classic Gameplay** — Rock, Paper, Scissors against the computer
- 🎲 **Random Library** — Computer makes random choices every round
- 🏆 **Score Tracking** — Your wins, CPU wins & ties tracked throughout session
- 🔥 **Win Streaks** — Tracks your current streak & best streak ever
- 💀 **CPU Streak Warning** — Alerts when CPU is on a winning streak
- 📈 **Stats Menu** — View full stats anytime during the game
- 📊 **Win Rate %** — Calculates your win percentage at the end
- 🎯 **Input Validation** — Handles invalid inputs gracefully
- 🖥️ **Clean UI** — Emoji-based formatted console interface

---

## 🛠️ Technologies Used

| Technology | Purpose |
|-----------|---------|
| Python | Core language |
| Random | Computer choice generation |
| Conditional Logic | Win/lose/draw detection |
| Loops | Game replay system |
